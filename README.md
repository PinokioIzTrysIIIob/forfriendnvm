# Печать героя

Веб-тренажёр слепой печати для отборочного этапа «Киберрывок 2026».

## Запуск

Нужен Python 3.10 или новее. Откройте терминал в папке проекта.

```bash
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимости и запустите приложение:

```bash
python -m pip install -r requirements.txt
python app.py
```

Откройте адрес из строки `Running on` в терминале. По умолчанию это http://127.0.0.1:5000. Если порт занят, приложение автоматически выберет следующий свободный. Если команда `python` не найдена, используйте `python3`.

## Как пользоваться

1. Можно сразу тренироваться без регистрации. Гостевой прогресс сохраняется в этом браузере. Чтобы войти с другого устройства и попасть в рейтинг, создайте аккаунт через «Войти» или ссылку под заголовком. При регистрации накопленные результаты переносятся в аккаунт.
2. Выберите язык, режим, сложность и набор упражнений. Для слов и предложений есть темы «Повседневная жизнь», «Учёба» и «Природа». Для кода — основы, циклы и функции, для HTML/CSS — разметка и стили. Для символов — буквы, цифры, знаки или всё вместе. Нажмите «Начать тренировку».
3. Печатайте текст в поле под упражнением. Таймер начинается с первого нажатия. После ошибки введите правильный символ: ошибочный ввод не продвигает курсор. Пробелы, регистр и отступы в коде тоже учитываются. Перевод строки вводится клавишей Enter, отступ из четырёх пробелов — четырьмя пробелами.
4. Правильные символы становятся зелёными, ошибка подсвечивается красным. Клавиатура показывает нужную клавишу и палец. Для возврата фокуса в поле с клавиатуры используйте Shift+Tab.
5. После последнего символа результат сохраняется автоматически. При ошибке сети нажмите «Повторить сохранение», не закрывая страницу. Кнопка «Прервать» отменяет незавершённую тренировку без начисления опыта.
6. В разделах «Мой прогресс», «Достижения» и «Таблица лидеров» можно посмотреть результаты.

## Что реализовано

- Случайные слова длиной 2–10 букв, предложения на русском и английском, код Python / JavaScript / HTML / CSS, сочетания букв, цифр и спецсимволов.
- Русская и английская раскладки, подсказки пальцев и исходной позиции рук, подсветка Shift и Enter.
- Текущие CPM, WPM, точность, ошибки, таймер, комбо и визуальные эффекты. Вставка готового текста отключена.
- Опыт и уровни, шесть достижений, случайный бонус двойного опыта на 10 секунд.
- Гостевой режим без регистрации: те же тренировки, уровни, достижения и статистика. Регистрация по email сохраняет гостевой прогресс, вход по паролю восстанавливает аккаунт.
- Общая статистика, последние 10 тренировок, графики скорости и точности за 14 дней, сложные символы и сочетания.
- Рейтинги по скорости, точности и опыту, фильтры «Сегодня», «Эта неделя» и «Всё время».
- Адаптивный интерфейс для компьютера и телефона. Приложение не использует внешние шрифты или сервисы и после установки Flask работает без интернета.

## Правила подсчёта

CPM = число правильных символов × 60 / время в секундах. WPM = CPM / 5, где одно условное слово — пять символов с учётом пробелов. Точность = правильные нажатия / все нажатия × 100%. Ошибка, Backspace или попытка пропустить символ не сдвигает курсор и сбрасывает комбо. Исправлять уже правильные символы не нужно. Прерывание не сохраняет результат и не меняет прогресс.

За символ даётся 1 XP. Множитель комбо: ×2 с 10 правильных нажатий подряд, ×3 с 25, ×5 с 50. В случайной точке упражнения включается удвоение опыта на 10 секунд. Бонусы не меняют реальную скорость. За каждые 200 XP повышается уровень: со второго доступны код и средняя сложность, с третьего — символы и высокая сложность.

«Стальной палец» учитывает последовательные правильные нажатия в завершённых упражнениях, в том числе между тренировками. Любая ошибка в сохраняемом упражнении сбрасывает серию. Другие достижения: первая тренировка, 200 CPM, упражнение без ошибок, 300 WPM, 10 тренировок.

На графиках скорость считается по общему времени и числу символов за день, точность — по всем нажатиям за день. День без тренировок не считается нулевым результатом. Сложные символы ранжируются по количеству ошибок на ожидаемом символе, сочетания — по предыдущему и текущему ожидаемым символам. Пробел обозначен `␣`, перевод строки — `↵`.

В рейтинге скорости используется лучший CPM за выбранный период; WPM приведён рядом. Точность рассчитывается по всем нажатиям, опыт суммируется. При равенстве показателей выше игрок с большим опытом за период. Неделя начинается в понедельник, даты и границы дней — по Москве. В таблице до 50 игроков. Гости не входят в общий рейтинг; после регистрации их результаты участвуют в нём. Незавершённые упражнения в рейтинг не попадают.

## Структура

- `app.py` — сервер, аккаунты, база данных, проверка нажатий, подсчёт результатов и рейтингов.
- `content.py` — тематические словари, 36 предложений на двух языках, 27 примеров кода, генерация упражнений и список достижений.
- `templates/index.html` — страница приложения.
- `static/app.js` — ввод с клавиатуры, обновление интерфейса, графики Chart.js.
- `static/style.css` — оформление.
- `static/vendor/` — локальная Chart.js 4.4.7 и её лицензия MIT.
- `tests/test_app.py` — проверки расчётов, аккаунтов, сохранения, доступа и рейтингов.

Для проверки:

```bash
python -m pip install pytest
python -m pytest -q
```

## Гостевой режим

Для гостя сервер создаёт временный профиль без email и пароля от пользователя. Прогресс хранится в SQLite, а браузер получает cookie сессии на 30 дней. После очистки cookie или истечения сессии восстановить гостевой профиль нельзя. При регистрации профиль становится обычным аккаунтом, все тренировки и достижения сохраняются. Вход в уже существующий аккаунт открывает его прогресс и не объединяет его с гостевым.

## Данные и доступ с другого устройства

База `instance/game.db` и секрет сессий `instance/secret.key` создаются при первом запуске. Пароли хранятся в виде хешей. Сервер самостоятельно пересчитывает результат по истории нажатий. Для резервной копии остановите приложение и скопируйте папку `instance`. Не добавляйте её в Git.

Для доступа по локальной сети запустите тот же сервер с `HOST=0.0.0.0`:

macOS / Linux:

```bash
HOST=0.0.0.0 python app.py
```

Windows PowerShell:

```powershell
$env:HOST="0.0.0.0"
python app.py
```

На втором устройстве откройте `http://IP_КОМПЬЮТЕРА:5000` и войдите в тот же аккаунт. Оба устройства должны обращаться к одному серверу: так прогресс синхронизируется через общую базу. После завершения упражнения свежие данные доступны на другом устройстве при открытии раздела или обновлении страницы.

Для публичного размещения нужен WSGI-сервер, например Waitress, и HTTPS перед ним:

```bash
python -m pip install waitress
waitress-serve --listen=0.0.0.0:5000 app:app
```

За HTTPS установите переменную `COOKIE_SECURE=1`. Также можно задать `PORT`, `DATABASE` и `SECRET_KEY` через переменные окружения. Это учебный прототип: история нажатий проверяется сервером, но защиты от автоматизированной печати нет.

## Материалы для сдачи

В папке находятся рабочий прототип, исходный код и инструкция. Локальный Git-репозиторий содержит исходники; его можно отправить в свой удалённый репозиторий и передать ссылку жюри. Папку `instance` с личными данными передавать не нужно.
